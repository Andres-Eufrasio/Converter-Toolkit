# PowerShell Converter Toolkit
Collection of Cdmlets for converting between diffrent file types, act's as a wrapper around FFmpeg for ease of use. Supports indivusual file conversion and batch processing within your directory tree.

## features
<ul>
<li>OPUS to MP3</li>
<li>Mp to MP3</li>
<li>OPUS to MP3</li>
<li>OPUS to MP3</li>
<li>OPUS to MP3</li>
<li>OPUS to MP3</li>
<li>OPUS to MP3</li>
</ul>

## requirements
requires PowerShell 5.1 or PowerShell 7+
FFmpeg available through system PATH
